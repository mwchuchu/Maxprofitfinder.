# Maxprofitfinder.
A python script to find Max Profit finder. Where month's profit is given in form of a list. Positive value is profit and negative is loss. A key is used as a constraint which tell us numbers of consecutive month's profit we will be comparing.
```bash
  month's profit= [2,-9,3,4,8,-7,-3,2]
  key = 6 (number of months to be selected for comparison).
```bash
